# 浪尖节拍 · Wavebeat Fishing 3D

直接游玩：https://2324621372.github.io/fishing3d-play/

3D 航海钓鱼：三航道换道、躲漂浮物、捞救生圈、压舷回稳、自动选饵与半圆扫针钓鱼 QTE。

- 左右方向键或 A / D：航行换道，侧浪时压舷与回稳。
- 空格：执行底部大按钮动作；提竿、每拍收线和抓鱼均需在半圆扫针进入亮区时点按，长按不会自动命中。
- 手机可点按钮或左右滑动。开局首道练习浪不扣血。
- 左上“返航结算”可结束本次航程。

此仓库只发布可直接游玩的静态成品。完整前后端源码、资源及构建说明保存在独立私有仓库。
公开浏览器版保存本机纪录；平台排行榜和 App 震动效果请在平台手机调试 App 的关联草稿中体验。
